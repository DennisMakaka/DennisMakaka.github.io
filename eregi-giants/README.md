# Eregi Giants Basketball Academy website

A responsive, dependency-free website foundation for Eregi Giants Basketball Academy.

## Run locally

From this directory, serve the files with any static server, for example:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Updating content

Edit `academyConfig` in `script.js` to update programs, impact placeholders and gallery entries. Replace placeholder image entries with approved academy photography. Configure official contact, WhatsApp and social links in `index.html` when those details are confirmed.

## Forms

The enquiry form validates required fields and protects submissions from public display. Before production, connect the submit handler to a secure backend or trusted form provider with server-side validation, spam protection, access controls and an appropriate privacy notice.
